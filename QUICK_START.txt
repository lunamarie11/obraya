❓ TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

P: No veo el botón "Admin" en login
R: Asegúrate que el servidor esté corriendo (npm run dev)

P: Carga infinita en dashboard
R: Revisa browser console (F12) para API errors

P: Token no persiste
R: Verifica en DevTools → Application → localStorage/cookies

P: Vuelvo a login cuando doy refresh
R: Normal si token expiró, login de nuevo
